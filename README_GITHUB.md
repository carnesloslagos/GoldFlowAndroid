# GoldFlow Android

Prototype Android app for Binance XAUUSDT order flow.

Includes Binance Futures public WebSocket, XAUUSDT aggregated trades, Delta, CVD, Depth 20 order book, bid/ask balance, CVD chart, and basic LONG/SHORT/ESPERAR display.

## Android Studio
Open this folder in Android Studio and let Gradle sync. Then use **Build -> Build APK(s)**.

APK: `app/build/outputs/apk/debug/app-debug.apk`

## GitHub
Upload the **contents of this folder** to a repository. GitHub Actions is configured to build the debug APK automatically.
